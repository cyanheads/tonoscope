# 0.1.1 — 2026-09-26

## Added

- **Source link**: a GitHub icon in the masthead and a line in the about panel's colophon link to the source repository.
- **Live site**: the instrument is served at https://tonoscope.caseyjhand.com as static assets on Cloudflare Workers (`wrangler.jsonc`).
- **`bun run deploy`**: runs the gate, builds, and uploads `dist/` with `wrangler deploy`.
- **Security headers**: `public/_headers` sets a strict CSP, `Permissions-Policy: microphone=(self)`, HSTS, and immutable caching for hashed assets.

## Changed

- **License**: Apache-2.0, replacing all rights reserved. The bundled IM Fell English font stays under the SIL Open Font License 1.1.

## Fixed

- **Resonator switch**: grains flying between resonators no longer blow out into a white blob; they shed their vibration glow and exposure dips until they land.
